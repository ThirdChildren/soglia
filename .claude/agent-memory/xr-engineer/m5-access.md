## Second round: Issues panel, menu and labels at large text (uniform scale, not dedicated layouts)

- Decision: the six screens of the Issues panel and the menu are packed to the millimetre in logic constants AND uikitml; a dedicated 3.0 cm layout per screen (as for View) would have meant touching ~6 logic modules and their tests. Instead the panel is made 1.25x bigger AS A WHOLE: `applyPanelLook(doc, root, 'scale')` scales fontSize + every length (width, height, margins, paddings, border width/radius, gap); the system multiplies the pick slots, the panel centre and the extent by `ui.scale` (`panelScale()` = 1.25 at large text, fixed when the panel opens); runtime-set lengths (bar button widths, icon sizes, item name fontSize) are multiplied in code. Same content, same pages, text exactly 3.0 (title 3.25).
- Cone: a 45 x 47 cm panel does not fit 30 deg at the normal anchor (32.5 deg). `pinnedMenuAnchor(..., large)` uses `PINNED_DISTANCE_LARGE` 0.60 and `PINNED_DROP_LARGE` 0.235 (panel centred on the eye line): 28.5 deg level, <= 30 for pitch +-8 (the clamp the anchor follows); beyond +-8 the cone is exceeded. Frame 0.64 m. Palm menu at large: `MENU_FRAME_MAX_DISTANCE_LARGE` 0.68 / `MENU_MIN_DISTANCE_LARGE` 0.58 (IWER: 30.0 deg at 0.66 m); sweep test in `tests/unit/large-panels.test.ts`.
- TRAPS found: (1) `properties.peek()` returns lengths from a UIKitML file as STRINGS (`'34.4'`), numbers only when set from code: parse both (`lengthOf`). (2) A node with no own fontSize reads the PARENT's: record every node's originals in a first pass BEFORE patching, or the child grows twice (3.75 instead of 3.0). The box default fontSize is 20: only remember sizes < 10. (3) A text that fills its box to the hair (`issue-panel-hint`) wraps differently once scaled: text widths get +2 % (`TEXT_AIR`). (4) `panel-theme` walk is idempotent through the originals WeakMap, so it can run again on a preference change.
- Labels: `src/logic/label-scale.ts` holds one number (`setLabelScale`, set by `installAccess`) and the cached normal/large extents (`roomLabelExtent()`, `fitLabelExtent()`, `reasonLabelExtent()`, `hintExtent()`) plus `labelFit`/`labelMinDistance` (0.58 m at large: the 1.25x FitCheck label at 0.52 m was 30.8-31.6 deg with the gaze down). The old `*_EXTENT` constants stay (normal values, tests). Label panels use `scale` mode.
- Coach banner of step `grab` now sits at eyes + 0.31 m (the large menu top is at +0.235).
- Measured (IWER, A, contrast + large, menu dimmed, sofa held over armchair, Fit and reason labels): 65 calls per view, as before. Issues panel verified in IWER on home, list, detail and the form (long pinch on the washer) at 45 x 47 cm; menu picks (chair) work through the scaled slots.
