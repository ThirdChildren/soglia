## Pieces and base
- Pinch point = grip, not the set pose. Piece/base target T: hand pose (Tx+0.038; Ty+0.003; Tz-0.037) identity. Carry with `xr_animate_to` 0.8 s, wait 1 s, `set_select_value 0`, wait 0.6-0.7 s. P1 (bed) pose (0.103;1.393;-0.602) -> 6.80/1.125; PB1 (0.063;1.393;-0.517) -> 6.06/3.00; PB2 (0.113;1.393;-0.607) -> 7.00/1.125 (exact in the rerun); wardrobe PW (0.133;1.393;-0.6395); armchair PD (0.083;1.393;-0.467), PS (0.138;1.393;-0.467); POUT1 (0.463;1.393;-0.487); POUT2 (0.638;1.393;-0.487). Re-grab a placed bed at its centre (0.103;1.393;-0.611) (z -0.611 for rot 0, -0.621 for rot 90).
- Wrist rotation: pose = G - R_y(a)*(-0.038,-0.003,0.037), quaternion (0,sin(a/2),0,cos(a/2)); compute with python (G=(0.065;1.39;-0.574)): -30 (0.1164;-0.587), -60 (0.116;-0.5596), -90 (0.102;-0.536). -60 -> `rot=90`, +60 from 90 -> `rot=0`. Tap = `xr_select {device:"hand-left",duration:0.2}` while the right holds (works with the left palm up at the menu).
- A left-hand grab: left hand at the piece pose + `xr_select 0.3` (right at rest) -> `hand=left`.

## Pan / zoom / drag (S2.9)
- Free base points B1/B2 = (Ox +- 0.35; Oy+0.03; Oz): pose B1 (0.388;1.383;-0.487), B2 (-0.312;1.383;-0.487). Pan: select 1, wait 0.4 s, animate, release. -0.15 -> `translated x=-0.150`; ->-0.30 clamps; diagonal: starting at root -0.30 the hand pose must go to **z = Oz+0.60-0.037 = +0.113** (not -0.127: arithmetic trap I fell into) -> (-0.134; 0.268).
- Two-hand with the preset at scale 0.12: hands at y = Oy+0.10 (pose y 1.453) so no piece is grabbed; zoom poses (-0.112/0.188 -> -0.562/0.638) -> 0.12; 10b LF/RF poses (0.044/0.248;1.453;-0.487) -> (0.244/0.448) -> `translated x=0.200` (works as in the scenario); 11 stage poses: 30 deg (0.258;-0.436)/(0.434;-0.538), 60 deg (0.295;-0.399)/(0.397;-0.575), 90 deg+0.10 (0.446;-0.385)/(0.446;-0.589) -> yaw 90.0, translated radius 0.300.
- Recenter = pinch the item with the right hand while the left palm is up; then palm down; root back to O.

## Tool / log gotchas
- Logs: `[soglia:state]` is huge with the preset (14 pieces): avoid patterns that match it (`furniture`, `miniature`, `translated|recentered|soglia:state` together); read `translated`/`recentered` alone with `since`. `since` (ms timestamp) on `browser_get_console_logs` is the cleanest way to isolate the current load/step.
- `browser_interact` wait: a single 4000 ms wait after `browser_profile start` was refused; use <= 3000 ms chunks (two waits in one call are fine).
- `ecs_query_entity` of a piece that was grabbed from the model fails in flight (new entity index): re-find with `ecs_find_entities` first.
- MCP calls take 0.5-3 s: a menu-closing palm-down followed by the second hand's palm-down 1-2 s later can open a spurious `menu opened hand=right` for the other hand (sequential artefact; set both hands in one go or accept it).
- Budget numbers (14 pieces, house A): 35 -> 49 calls/view (menu closed), worst case (0.12 + menu + held piece + label) 72-74; blocks fallback 63 calls, 22.3k tris.
